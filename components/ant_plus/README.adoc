= ant_plus

ANT+ heart rate monitor for any ESPHome device, e.g. an nRF52840 on Thread or an
ESP32. It reads the ANT+ data from a second chip, an nRF52 running the
https://github.com/randybb/nrf-ant-bridge[nrf-ant-bridge] firmware, over UART.

The ANT stack runs on the bridge because it only works on nRF Connect SDK 2.9
(sdk-ant v2.0.0). On NCS 3.4, which ESPHome's nRF52 support needs, the channel
opens but never receives anything.

== Configuration

[source,yaml]
----
external_components:
  - source: github://randybb/esphome-components
    components: [ant_plus]

uart:
  rx_pin: GPIO16  # bridge TX
  baud_rate: 115200

ant_plus:
  device_number: 655730
  heart_rate:
    name: Heart Rate
----

[cols="1,1,3",options="header"]
|===
|Option |Default |Description
|`device_number` |`0` |ANT ID of the heart rate monitor, as shown by Garmin devices; `0` takes whichever monitor the bridge pairs with
|`heart_rate` | |Heart rate sensor. Goes `unknown` 5 s after the last page
|===

The bridge sends 3-4 updates a second. Add `filters:` (e.g. `throttle` or
`delta`) to the sensor to send fewer to Home Assistant.
